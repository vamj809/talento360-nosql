# Talento360 NoSQL

Mini-aplicación académica para gestionar una evaluación de desempeño 360° usando MongoDB como motor NoSQL principal.

## Caso empresarial

Una empresa de 800 empleados necesita configurar ciclos de evaluación, asignar evaluadores, recolectar evaluaciones anónimas y generar reportes individuales y agregados para RRHH.

## Stack

- Next.js
- MongoDB
- Docker Compose
- Node.js

## Ejecución local

```bash
docker compose up --build
